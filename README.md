# TomTroc

Application web d'échange de livres développée en PHP et MySQL.

## Installation

1. Cloner le repository dans le dossier `htdocs` de XAMPP.
2. Créer une base de données dans phpMyAdmin.
3. Importer le fichier `tomtroc.sql` dans cette base de données.
4. Vérifier et modifier si nécessaire les paramètres de connexion à la base de données dans `config/config.php`.
5. Démarrer Apache et MySQL depuis XAMPP.
6. Accéder au site depuis : `http://localhost/nom-du-dossier/`
